    Overture Maps の使いどころ

    • buildings
      建物の色分け各建物の sources[0].dataset を読み、OSM か AI 由来かを判定
    • divisions
      地名検索・エリア名町丁目と市区町村の名前・位置・所属を使用
    • places
      駅名検索・目印のピン駅約1,200（位置のずれた投稿は除外）と、大学・病院・役所・商業施設・学校・公園・スーパー・コンビニ約2.9万件

      How it works

      このマップの仕組み

      1. データ — Overture Maps Foundation の 2026-09-23.1 リリースの建物データ（GeoParquet）を、首都圏の範囲で読み込みました。前処理は build_*.py の Python スクリプトです。
      2. 出どころの判定 — 各建物の sources[0].dataset が OpenStreetMap なら「人が描いた」、Microsoft ML Buildings と doi:10.5281/zenodo.8174931（East Asian Buildings）なら「AIが見つけた」としています。どちらも衛星画像から機械学習で建物を抽出したデータです。
      3. なぜ OSM 編集候補になるのか — Overture は OpenStreetMap の建物を優先し、OSM に建物がない場所を AI 由来の建物で補っています。つまり AI の建物が多い場所は、OSM にまだ描かれていない建物が多い場所です。
      4. 集計 — 約450mのマスごとに棟数を数えています。エリアレポートは、選んだ地点から半径1km以内のマスの合計です。ドット表示の点はマスの中にランダムに置いており、1点が何棟にあたるかはズームで変わります（凡例に表示）。
      5. 建物の形 — 淵野辺（青山学院大学 相模原キャンパス周辺）だけは、建物1棟ずつの形を取り出しました。ズームすると表示され、クリックで出どころと OSM の更新年がわかります。

      AI の検出には誤り（建物でない物の検出や、形のずれ）が含まれることがあります。OSM に描くときは、航空写真や現地で確認してから編集してください。
